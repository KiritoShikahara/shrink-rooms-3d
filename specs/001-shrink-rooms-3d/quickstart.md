# クイックスタート / 手動テスト

## 開く
1. UE 5.7.4 で `ShrinkRooms3D/ShrinkRooms3D.uproject` を開く。
2. `L_Title` を開き PIE で実行。

## 操作
WASD/矢印 = 移動、R = リトライ。

## 確認チェックリスト
- [ ] タイトル → ステージ1 が始まる
- [ ] 移動で1ターン進む。壁/鉄箱に当たると進まない
- [ ] 箱を1個だけ押せる。2個連続は押せない
- [ ] 残り手数が HUD に出て、毎ラウンド終了時にスケジュール通り壁が縮む
- [ ] 木箱は押せなくなると潰れ、鉄箱は壁を止める
- [ ] プレイヤーが潰されると GameOver、R で再開
- [ ] 鍵 → 扉、感圧板 → 扉、落とし穴(即死/箱で埋まる)
- [ ] 収縮と同ターンの出口到達はクリア
- [ ] ステージ1〜5を通しクリア → AllClear → タイトル
- [ ] 再起動後に到達ステージが残る
- [ ] サイズ: プロジェクトフォルダ(Saved等を除く)が 2GB 未満
