# 機能仕様: Shrink Rooms 3D (5ステージ版)

**Feature Branch**: `001-shrink-rooms-3d`
**Created**: 2026-11-10
**Status**: Draft
**参考**: Steam「Shrink Rooms」(2D トップダウン Sokoban 系パズル)の3D版
**前提**: UE5.7.4 / Blueprint のみ / 個人制作 / 後期課題(`doc/後期課題_要件まとめ.md`)

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 1ステージをクリアする (Priority: P1)
プレイヤーはグリッド状の部屋で、箱を押しながら出口へ向かう。ターンごとに壁が縮む。圧死せず出口に着けばクリア。

**Why this priority**: これだけで「ゲームとして成立」する最小単位。
**Independent Test**: 1ステージだけで、開始 → 移動 → クリア表示まで通せる。

**Acceptance Scenarios**:
1. **Given** ステージ開始、**When** 方向入力、**Then** プレイヤーが1マス移動し1ターン経過する。
2. **Given** 箱の隣、**When** 箱方向へ入力、**Then** 奥が空きなら箱ごと1マス動く。奥が壁/箱なら動かない(ターンも消費しない)。
3. **Given** 出口(鍵で開く扉の先)に到達、**When** 到達時、**Then** クリア表示を出す。

### User Story 2 - 壁の収縮と失敗/リトライ (Priority: P1)
壁は毎ラウンド(1ターン)の終了時に収縮する(Steam 準拠: contract inward at the end of each round)。限られた手数で脱出できなければ潰される。失敗時は即リトライできる。

**Independent Test**: 何もしないで規定ターンを経過させ、失敗表示とリトライを確認する。

**Acceptance Scenarios**:
1. **Given** ターン終了時、**When** ステージの収縮スケジュールに該当、**Then** 指定の辺の壁が1マス内側へ移動する。残り手数(脱出期限)を表示する。
2. **Given** プレイヤーが壁になるマスにいる、**When** 収縮、**Then** ゲームオーバー表示。
3. **Given** 箱が壁になるマスにある、**When** 収縮、**Then** 箱は押し潰されず、壁は止まる(仕様: 箱は壁を止める)。
4. **Given** ゲームオーバー、**When** リトライ入力、**Then** 同ステージを初期状態から再開する。

### User Story 3 - ギミック(前期要素の流用) (Priority: P2)
鍵・扉・感圧板・落とし穴(即死)を使ったパズルを解く。

**Acceptance Scenarios**:
1. **Given** 鍵を取得、**When** 扉へ入力、**Then** 扉が開く(未取得は開かない)。
2. **Given** 箱または自分が感圧板の上、**When** 乗った間、**Then** 紐づく扉が開く。離れると閉じる。
3. **Given** 落とし穴、**When** プレイヤーが入る、**Then** 即死(ゲームオーバー)。箱が入ると穴が埋まる。

### User Story 4 - 5ステージの進行とタイトル (Priority: P2)
タイトル → ステージ選択/順次進行 → 全5面クリアでエンディング。

**Acceptance Scenarios**:
1. **Given** タイトル、**When** スタート、**Then** ステージ1が始まる。
2. **Given** ステージクリア、**When** 次へ、**Then** 次ステージへ進む。
3. **Given** ステージ5クリア、**When** 完了、**Then** 全クリア表示とタイトルへの戻りができる。
4. **Given** クリア済み、**When** 再起動、**Then** 到達ステージが保持される(講義013のセーブ機能)。

### Edge Cases
- 同時に複数の箱を押す入力: 押せるのは1個のみ(連続箱は押せない)。
- 収縮と同ターンに出口へ到達: 到達を優先してクリア。
- 入力連打: 前の移動アニメ中は入力を受け付けない(ターンの二重消費を防ぐ)。
- 箱が詰んだ状態: リトライで回復できる。

## Requirements *(mandatory)*

### Functional Requirements
- **FR-001**: グリッド移動(4方向)とターン管理を提供する。1有効入力 = 1ターン。
- **FR-002**: 箱押しを提供する(1個のみ、奥が空きの時のみ)。
- **FR-003**: 壁収縮はラウンド(ターン)終了時に、ステージごとの収縮スケジュール(ターン番号 → 動く辺/量)に従って行う。収縮は毎ターン起こり得る。残り手数を UI 表示する。
- **FR-004**: プレイヤーが潰される/落とし穴に入ると、ゲームオーバーとリトライを提供する。
- **FR-005**: 鍵・扉・感圧板・落とし穴・出口(ゴール)を提供する(前期の BP_Key/BP_Door/BP_Goal/BP_DeadObject/BP_SwitchButton 相当)。
- **FR-006**: トップダウン固定カメラ。3D のメッシュ/ライティングで部屋を表現する。
- **FR-007**: 5ステージ(難易度は漸増。導入 → 箱 → 鍵/扉 → 感圧板 → 落とし穴 + 総合)。
- **FR-008**: タイトル、ステージクリア、ゲームオーバー、全クリアの各画面(UMG)。
- **FR-009**: 到達ステージのセーブ/ロード。
- **FR-010**: ステージはデータ(DataTable かレベル配置)で定義し、新規ステージの追加を容易にする。
- **FR-011**: 入力は Enhanced Input(キーボード WASD/矢印 + リトライキー)。
- **FR-012**: 手動プレイテストのチェックリストを各ステージに用意する(自動テスト基盤は対象外)。

### 非機能・制約
- UE5.7.4、Blueprint のみ、標準プラグインのみ、リポジトリ 2GB 以下、`.gitignore` 必須。
- 評価観点: 実装量、BP の読みやすさ(コメント/命名/整理)。

### Key Entities
- **Grid/Cell**: 座標、種別(床・壁・穴・感圧板)。
- **Player**: グリッド位置、所持鍵。
- **Box**: グリッド位置。
- **Door/Key/PressurePlate/Pit/Goal**: ギミック。ID で相互に紐づく。
- **ShrinkWall**: 現在の内側境界、収縮間隔、残りターン。
- **StageData**: 範囲、初期配置、収縮間隔、制限。
- **SaveData**: 到達ステージ。

- **FR-018**: 次の収縮で動く辺の壁を赤く光らせ、HUD に「次の収縮: 辺とターン数」を出す。
- **FR-019**: ポーズメニュー(Esc)、ステージ選択(ロック付き)、ステージごとの名前とヒントを提供する。
- **FR-020**: ゲームオーバー画面に原因(壁に潰された/落とし穴)を、クリア画面に使用ターン数を表示する。
- **FR-021**: 移動、押す、扉、収縮、潰れる、鍵の取得に効果音と演出(補間、画面揺れ、ヒットストップ)を付ける。画面揺れは設定で切れる。

## Success Criteria *(mandatory)*

- **SC-001**: 起動から全5ステージクリアまで、クラッシュや進行不能なく通せる。
- **SC-002**: 各ステージに少なくとも1つの解法があり、チェックリストで確認済み。
- **SC-003**: 失敗 → リトライが2秒以内で完了する。
- **SC-004**: 前期要素(扉・鍵・スイッチ・即死・ゴール・UI・セーブ)を5種以上使用している。
- **SC-005**: リポジトリが 2GB 未満で、クリーンチェックアウトから開いて起動できる。

## Assumptions
- 単一プレイヤー、Windows、キーボード操作。
- アセットは UE 標準(Starter Content など)か無料素材の最小限。
- 壁収縮の対象は部屋外周(矩形)のみ。ストアページ記載の Portal Wall / Polymer / Anchor Crate / Clicker は、詳細仕様が公開されていないため初期スコープ外(拡張候補。5面完成後に検討)。
- 元作品のハブ(自由移動のレベル選択)・ヒント・実績・多言語は対象外。レベル選択はメニュー式にする。Undo はストアページに記載がないため対象外(リトライのみ)。
- ステージ数は5面。ヒント機能・実績・多言語は対象外。

## Clarifications (2026-11-10)
- 基本ルールは Steam ストアページ準拠(2026-11-10 追加指示): 箱を押してゲートを開け、毎ラウンド終了時の壁収縮で潰される前に、手数を計画して脱出する。ターン制、落とし穴・罠あり。
- 収縮タイミング: ラウンド終了時(毎ターン)。ステージごとの収縮スケジュールで、どの辺が何ターン目に動くかを定義する(ストアページに詳細記載なし → 仮定)。
- 箱と壁: 収縮先に箱があれば、箱がさらに奥へ押せる限り押して移動する。押せなくなったら、木箱(通常の箱)は潰れて消える。鉄箱は潰れず、壁がそこで止まる(プレイヤーは詰み得る → リトライ)。
- 箱の種類は2つ: 木箱(潰れる)、鉄箱(潰れない)。
- 締切・配点: 考慮しない。
- 仕様のスコープ: 修正(バグ修正・バランス調整)とグラフィックス向上(マテリアル、ライティング、ポストプロセス、VFX、演出)まで含める。

## 追加要件
- **FR-013**: 木箱は収縮で潰れる。鉄箱は潰れず壁を止める。
- **FR-014**: 収縮は、箱が押せるなら押して移動し、押せない場合のみ潰れる/止まる。
- **FR-015**: グラフィックス向上(マテリアル、ライティング、ポストプロセス、VFX、サウンド、UI演出)を行う。ただしサイズ(2GB)と標準プラグイン制約を守る。
- **FR-016**: 全ステージ通しプレイ後の修正フェーズ(バグ修正、難易度調整、操作感)を設ける。
